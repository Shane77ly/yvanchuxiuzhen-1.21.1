# 验证选择与证据登记

已核对范围：两个 MCreator 生成的 1.18.2 Forge Mod 合并移植的调查与方案阶段采用的验证方针；尚未经过实施批次检验。项目可规定不同的测试政策，以项目为准。

## 证据等级

| 等级 | 说明 |
| --- | --- |
| 静态源码核对 | 人工读取的具体来源位置及结论 |
| 自动化验证 | 构建、提取器、测试、资源引用检查等可复现命令及结果 |
| 来源版本实机 | 在来源游戏版本中的实际行为记录 |
| 目标版本实机 | 客户端、专用服务器、多人与存档场景的实际结果 |
| 两版本对照 | 同一场景在两个版本中的结果比较 |

静态注册、事件挂载、正确运行、行为对齐分别记录，不以一个含糊的“完成”覆盖不同证据。没有执行的检查写“未执行”。

## 按风险选择验证

| 改动 | 验证方式 | 不做的形式工作 |
| --- | --- | --- |
| 公式、概率、取整与币值 | 从来源代码独立推导算例；在易回归规则上编写少量确定性测试 | 把实现表达式复制到 expected；`assert true`；给每个参数写相同测试 |
| 附件/组件与死亡复制 | 保存后重读、重登、死亡/非死亡复制的实际结果 | 仅断言对象非空或字段存在 |
| 菜单/网络/库存/账户 | 当前玩家与装置绑定、移动物品、多玩家操作、扣费与产出的实际结果 | 把每个普通方法包成无必要的 mock 测试 |
| 注册、文本和纯资源 | 构建、资源解析、游戏查看；必要时批量引用检查 | 对每个注册 getter 建测试 |
| 实体/技能/特效 | 服务端行为与真实客户端的动作、命中、视觉、声音对照 | 用编译成功代替游戏和视觉验收 |
| 曾复现的 Bug、共享基础逻辑 | 能稳定重现问题的针对性回归 | 为假设中的分支补大量测试 |

每条测试说明它能发现哪种真实错误；能由现有编译或游戏场景充分验证的变更，不另建测试套件。性能记录机器、场景、实体/玩家规模和测量结果，不预填“已优化”。
