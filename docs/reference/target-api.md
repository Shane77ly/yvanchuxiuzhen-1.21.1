# 目标 API 核对

本轮先查阅本地 NeoForge 21.1.228 源码。最初的源码根目录为邻近工程的 `reference/neoforge-21.1.228-sources`（位置见[1.18.2 工程入口](legacy/README.md)）；开发环境建立后，以构建生成的 `build/moddev/artifacts/neoforge-<版本>-sources.jar` 为准，其中另含 Minecraft 源码。当前构建为 21.1.265；本页与数据文档中依据 21.1.228 源码得出的结论尚未在 21.1.265 源码上复核，依赖该结论编码前以当前 sources jar 核对。

已确认的源码事实以移植技能的 [NeoForge 1.21.1 参考](../../.claude/skills/minecraft-mod-porting/references/targets/neoforge-1.21.1.md)为正文，依据均为本地源码；外部文档检索本轮未返回可用正文。本页记录本项目据此仍需验证的范围。这些证据支撑架构边界，不能替代编译和游戏验证。新项目尚无 Java 实现。

| 机制 | 本项目仍待验证 |
| --- | --- |
| 延迟注册/命名空间 | 一个实际 Mod 中两个 1.18.2 命名空间的资源、标签、结构、网络和打包完整运行 |
| 玩家数据与死亡 | 每类档案的死亡/寿尽/轮回政策、事件顺序及持久化验证 |
| 附件同步 | 选择实际所需的同步范围；可变对象修改后的通知和保存 |
| 物品组件注册 | ItemStack 组件 codec、网络编码、相等性和实际消费者 |
| 实体复制事件 | 与附件自动复制协作时不会重复执行玩法损失/奖励 |
| 网络注册 | 实际协议、长度约束、身份/菜单校验与拒绝路径 |
| 网络执行线程 | 所有玩法修改在服务端主线程 |
| 服务端重载 | 按真实配置需求选择加载时机；本项目尚未采用全系统运行中热重载 |
| 伤害入口 | 1.18.2 每个攻击前置规则应放在哪个阶段，逐入口对照 |
| 伤害应用与结果 | 词条、反击、击杀奖励使用对应阶段 |

邻近工程的 `reference/vanilla-1.21.1` 只是数据参考；Minecraft Java 源码以构建生成的 sources jar 为准，上表待验证项可据此逐项核对。本轮只设计数据归属，不凭空指定未核实构造签名。

基础构建组合已解析并通过构建与客户端/专用服务器加载检查，见[架构](../development/architecture.md)“技术依赖”；不声称为最新版本。第三方库的具体组合仍须在[阶段 B](../development/roadmap.md)按实际需求解析和启动验证。
