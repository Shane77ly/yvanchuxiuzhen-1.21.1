# 炼器、图纸、熔炼与修理

八鼎自然入口、库存、界面、四类炉次和装料领取已实现并完成静态源码核对；构建、实际游戏与两版本对照的结果分别记录在[月志](logs/2026-11.md)，代码实现不代表验收通过。来源采用[系统导航](../README.md)的 A/B 规则，逐项见[来源证据](ledger/source-evidence.csv)。

## 数据所有者与公开操作

## 开始与四类炉次

`B:LianqiBegin:34–441`仅空闲分派，顺序为：图纸空且0槽为六类器物时先升级；图纸空时先普通熔矿，再四类材料精炼；最后图纸`fabaoid`非空时制作。升级检查游戏规则、1至8至少一材料及旧器物非空`fabaotype`；图纸制作的数量不足只提示且不移游标，可同槽重复提示；ID不同跳出，空要求跳过。制作和升级无通用成品空检，能覆盖未领取成品。

熔矿启动时长3；精炼启动混计201、203、211、213总数至少4、时长5。精炼完成时仍需同类四件，混合够数可能空跑后停炉。熔矿只取`SMELTING`配方，每次产一耗一，不采用配方结果数量和经验；已有成品只匹配相同物品身份。精炼空成品按上述四类优先，有成品固定原料，每次按九槽顺序扣同类四件并产一个melt。成功保留开始位、进度归零；满槽或不足清炉次。

每次计划刻火力符至少1即喷岩浆并增计时，空闲也执行，12000次后清值。炼制且灵力足够时，进度加`1+firepower`、扣鼎等级；不足仅喷怒气粒子并保留进度。制作/升级完成交付保存物品或火药“灰烬”，清隐藏槽和计时；随后仍按来源用清零后的数值计算进度百分比。

## 材料累计与成品

有效材料目录来自`B:Worldbegin:43–46`世界加载表，复用material的225条有序定义，包含经验、特殊标记和附魔占位。制作只算图纸要求非空且非“空”的位置；未在有效目录的材料不消费。等级至少1，按品质加3截取条目；贡献乘品质倍率、单位重量乘0.2与数量，品质4、3、1为1.15、1.05、0.95，其余0.85。未知属性沿前一工作变量，附魔按名称合并并保留首次命名空间，器灵乘2。匹配材料立即扣除，失败不返还。完整公式定位为`B:Lianqijisuan:112–267`及`B:Lianqiuplevel:151–426`。

来源缺陷：目录中的`cailiao_190/`、`220/`、`230/`没有重量。默认`split("/")`丢弃尾空串，`B:Lianqijisuan:122`及`Lianqiuplevel:208`先读取不存在的第二项而抛错，尚未进入字符串数值转换。190是已注册且允许放入的碎灵石，该异常可达；220/230未注册。目标保留缺失重量时抛错，不补零或跳过材料。

时长先累计数量乘5，再乘`1-鼎火力*0.05`取整；重量累计单位重量乘数量，再乘`1-鼎提纯*0.01`取整。升级用实际调用的小写`Lianqiuplevel`：读取或按42项经验表反推旧累计量，清被升级整栈，按其余槽整栈累计；新增重量至少1后加旧重量。仅保留四本命字段，不整体继承旧物品任意标签、耐久和原生附魔。

重量至少160保存铁块“废弃金属”；至少250再设2次计划刻延迟与四舍五入重量除20的爆炸等级。此分支不执行等级计算，也不清旧失败标记。爆炸在计划刻末独立处理，与能否供热完成无关。

正常结果由equipment解释原始量、构造最终值和原生属性，遵守Q17。属性与附魔重量衰减为两张不同表，物攻不乘通用衰减，速度、攻速、击退、护甲和韧性保留来源例外。等级按4100、4000至100、1降序对应41至0，非正经验未命中仍保留来源默认41。隐藏槽完整物品保存后清空，待领经验为等级。等级高于`(鼎等级+共享炼器等级)*5`时，失败率差值乘0.1、不钳上限，开始时决定而完成时消费。

## 图纸、装料与领取

保存限空闲、六类模板加材料且载体尚无`fabaotype`；任意载体可写。保存模板名、ID、类型和材料01至08的ID/数量/显示名，不写00，不消费模板或材料，载体设一件。

装料先退还并清0至8，不锁运行中操作。仓开启按等级41至1、品质4至0逐桶扣，每桶替换同一鼎槽，不足不转背包；后桶覆盖前栈、跨图纸槽共用跳出标记、清等级不减等级计数等顺序由storage炼器专用操作保存。仓关闭只找一个足量玩家实体物品能力栈，不合并多个小栈。

领取先发待领炼器职业经验并清值，即使成品为空。材料逐件生成实例：201至209和211至219对应等级3、8、13、18、23、28、33、38、40，其余沿来源局部等级0；每件随机品质后交付。非材料保留原栈组件交付，最后清槽。

`build compileSmokeJava`通过，含既有`test/check`。复用项目内置`equipmentproduct`客户端，在原有28项后补充8项库存、网络与炉次检查；最终36项全INFO、0FAIL、DONE。客户端停止阶段有一条Netty `ClosedChannelException` ERROR，之后完成四维度保存，退出码0；未重复运行。前两轮失败、修正及最终证据见[月志](logs/2026-11.md)，完整批次验收仍受下述边界限制。

客户端已通过的八鼎样本限01鼎：真实物品放置和右键开窗、十一可见槽与隐藏槽隔离、成品禁手取/禁插入、图纸保存不耗材料且载体压一、仓逐桶覆盖与背包整栈装料、无热暂停、炉次及完整计划成品序列化重读、丹火自然供热完成、成品组件双端同步、按钮领取与四点职业经验、自然升级扣除旧器物及材料并继承小数累计。第二轮升级检查的累计原料生命期望误写448.8，按来源公式修正为428.4后通过，实际双精度值428.40000000000003。

专服02鼎另以受控写入起炉状态、物料和热量验证真实每20刻计划推进：60游戏刻后2个粗铁剩1个并产1个铁锭，热量20降14；再140刻后产物累计2个铁锭、原料空、开始位false/最大时长0、热量2。四件`cailiao_201`精炼产一件`cailiao_202melt`，原料空、开始位false/最大时长0、热量0。该样本验证计划刻及产出，未通过自然按钮启动熔矿/精炼。清理探针、解除强制加载及冻结后，原生stop正常保存四维度，退出码0、ERROR/FATAL均0。

客户端序列化重读在同次游戏内新建BE副本；专服虽完成磁盘保存，均未覆盖退出重登后的恢复或区块重载。最终成品截图已查看，灵力与鼎属性文字正常，但默认缩放存在裁切，不能据此认可完整视觉。其余七档自然放置、08专用放置物品、自然按钮熔矿/精炼、超重废料/延迟爆炸、失败概率、规则切换、帮助按钮和全自动化路径尚未专项验收。
