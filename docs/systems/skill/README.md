## 公开操作

已对照 `typed_field_accesses.csv` 汇总来源技能字段的外部读写：原归 panel 的04页读写技能栏16槽（各48处）、页 `jinengweizhi`（读29写4）、身法 `qinggong`、轻功 `flyjineng`、武器技 `wuqiskill`，本批按实际职责将装配菜单移归 skill；fulu 重置全部技能字段（各1处写）；equipment 读箭种选择 `arrowlinshi`（24读2写）与武器技 `wuqiskill`（14读）。代码为 `system/skill/api/Skills`；panel 只通过公开打开入口和导航事件协作，不再直接持有技能槽写入。完整重置随对应阶段补充。

| 操作 | 形式 | 调用者 |
| --- | --- | --- |
| 查询技能书 | `book(物品)` → `SkillBook`（类别、名字、品阶、所需境界、灵根要求、研习者、参数表）；`gradeText/levelText` 复用本系统中文计算只读显示 | book、本系统装配页、equipment 等 |
| 查询、放入、取出技能栏 | `state(玩家)`、`spell(玩家, 槽)`、`setSpell(玩家, 槽, 物品)`；`movement`、`flight`、`weaponArt` 与对应 `set…` | 本系统装配菜单、equipment（武器技） |
| 当前选择 | `selected(玩家)`；页、按键序号、技能栏序号与连招开关在 `state(玩家)` | panel、HUD |
| 箭种选择 | `arrow(玩家)`、`arrowChoice(玩家)`、`canSelectArrow(玩家, 序号)`、`selectArrow(玩家, 序号)`；`setArrow(玩家, 物品, 序号)` 供重置 | equipment、技能界面与 HUD；选择请求由服务端验证库存或灵力 |
| 轻功开关 | `flying(玩家)`、`setFlying(玩家, 值)`、`toggleFlight(玩家)`；写入值本身不改原生能力，开关操作按来源条件处理能力与掠空状态 | 轻功按键、equipment、fulu 重置 |
| 飞行减耗的饰品附魔 | `FlightEnchantmentEvent`：查询四个饰品槽的 `flying` 附魔等级之和；监听者 `add` | equipment 已提交保存后的四槽；菜单关闭前替换的新物品不提前计入，四甲由 skill 直接查询 |

| 冷却 | `cooldown(玩家, 分组)` | panel、HUD |
| 格挡显示 | `guardRemaining(玩家)` → 剩余刻数，只同步本人；不参与伤害减免 | panel、HUD |
| 妖化请求 | `DemonTransformationEvent(玩家)`：菜单第19号按钮请求，equipment 检查条件并处理库存、防具及计时 | equipment；生命周期与实例所有权见装备正文 |
| 打开技能界面 | `openMenu(玩家)` → 无槽技能菜单，按钮消息绑定本人当前容器ID并允许出窍旁观状态归窍 | G 键、panel |
| 打开装配页 | `openLoadout(玩家)`、`openLoadout(玩家, 最终BlockPos)` → 来源 `player_gui_04` 的八槽原生装配菜单；功法槽复用 `Techniques.slot/setSlot` | panel 三页导航与K键恢复 |
| 装配翻页与导航 | `turnPage(玩家, 步长)` 复用既有页状态；`SkillPageEvent` 请求01/03页，由 panel 执行打开与记页 | 本系统装配菜单、panel |
| 研习 | `study(玩家, 书)`：已被研习提示、境界与灵根条件（`RootRequirement`）、记下研习者 | book（右键） |
| 答题完成 | `completeQuiz(玩家, 书)`：覆盖技能书研习者，复用普通研习的书实例写入；不检查境界、灵根或既有研习者 | book（答题答满）；提示与关闭由book负责 |
