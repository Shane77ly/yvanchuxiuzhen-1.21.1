# 符箓知识、制作与释放：架构调查与提案

来源事实与目标方案分别陈述。目标方案未批准；源码定位采用 [系统导航](../README.md)的 A/B 规则。
## 1.18.2 结构

玩家 `huafufutou/huafutiandizhu/huafufudan` 保存知识选择；制作表来自 `list.yvanchuxitong.fululist`。`B:HuizhifuluProcedure:80–128` 匹配符头/符胆，按天地柱选择四种墨条及等级，使用 `RuneLEVEL + 1` 判断，再给成品写 `fululevel`。经验为 `(fululevel * 2)^2 + 4`。

绘制菜单有纸/墨/成品；烧灰台是另一加工流程。51 个编号符箓物品还有对应弹体、实体、持续效果及回调。轮回符 `A:Fulutexiao37Procedure` 主动重置玩家多项数据，其生命周期不能并入普通攻击符。

## 目标所有权与接口提案

定义为知识条目、组合配方和释放效果；玩家保存已学知识与职业；成品组件保存符箓等级和实例信息；符台保存槽位/加工状态。UI 当前选择是菜单状态，不作为全玩家第二份规则库。

入口分别为学习知识、选择组合、预览/绘制、烧灰、施放。施放交由能力执行时保留符箓消费和特殊效果边界，轮回调用成长的专用操作，传送调用世界服务，伤害通过战斗入口。

## 对照要求

每张编号符箓都记录获取、制作/其它获取路径、使用条件、物品消耗、实体/声音/粒子和结束动作。不同等级成品合并条件以来源为准，不因 Item ID 相同就混合不同等级。数值和轮回保留字段需负责人批准后实施。
