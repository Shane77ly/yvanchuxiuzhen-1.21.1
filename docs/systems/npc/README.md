## 公开操作

`NpcStructureReleases`以LOW优先级订阅World结构后处理事件，按来源刷新03号计分板并补充花繁城09/10/11；21号任务按真实居民注册身份匹配，现已接回来源居民族；完整自然任务仍属R13。结构顺序及有限验证见[World月志](../world/logs/2026-11.md#2026-11-14-固定结构解封与镇妖塔后处理)。

`NpcDefinitions.snapshot()` 返回来源拍卖修士目录副本；`AuctionNpcRequestEvent`由经济系统请求，本系统提供目录。来源`Npcshujvjiaru`只生成维度`worlddata`中的NPC定义，不涉及玩家能力字段；已对照`typed_field_accesses.csv`，不得由经济系统反写修士目录。

`NpcDialogueRequestEvent`提交玩家、按来源顺序的对话/任务脚本、商品表及商店说明，任务系统选择第一个未完成脚本。对话会话与任务目录由任务系统独占写入，商品与商店说明由经济系统的公开操作写入。对应`PlayerRightClickEntity`的`renwuitem/renwuliebiao/productlist/shopinformation`外部读写，修士系统不持有这些玩家附件。

乾坤道人/门徒两方块、两物品、两方块实体及零槽管理菜单已接入，本批补齐编号/烟雾同步、中文动态文本和可复现资产转换；必要客户端单项43条INFO、0 FAIL、DONE，含真实保存重进；中文编号/加号及整段金色截图已复看，完整模型动画与自然获取仍未验。门徒任务脱接与命令字段类型Q153/Q154、NPC档案消费者覆盖及完整自然投放仍开放。天道NPC管理已补齐NPC所有者五基类的档案交付与来源写入顺序，四代表实体资质/属性/20END及真实保存重进通过；两个旧粒子数量检查仍失败，完整报告见本月记录。其他所有者及原版Mob档案缺口、提示文案差异仍见[Q149/Q150](architecture.md#q149-管理工具档案消费者覆盖范围)。本轮变化见[修士月志](logs/2026-11.md)。

`NpcFollowers.follow(Entity, ServerPlayer)`与`stopFollowing(Entity)`由本系统唯一写入剧情跟随标志和玩家UUID。来源对任意Entity登记，LivingEntity的tick消费，实际Mob每20刻在同维度寻找主人并向其XZ各±2随机位置以速度1寻路；来源Forge LivingUpdate在LivingEntity.tick开头，目标使用EntityTickEvent.Pre。Quest只调用公开操作，跟随保存于实体持久数据；本批未作自然跟随实机验收。
