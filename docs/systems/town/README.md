# 城镇

标识 `town`，类别：系统。职责：城镇建设、居民与建筑（[系统设计](../../development/system-design.md)）。

## 公开操作

城镇规划、材料库存、`build_data`与中心案台所有权由本系统维护，外部不直接写入方块持久数据。当前建设路径无外部写操作；规划卷轴通过`Relations.entityTeam(player)`读取玩家实体团队，覆盖`typed_field_accesses.csv`中卷轴放置过程的`team`读取。中心所有权使用当前实体UUID，物资直接来自本系统容器，不访问其他系统玩家附件。

本轮变化见[城镇月志](logs/2026-11.md)，规则、来源缺陷和开放范围见[正文](architecture.md)。
