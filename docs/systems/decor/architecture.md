# 装饰：架构调查与提案

来源事实与目标方案分别陈述。目标方案未批准；源码定位采用 [系统导航](../README.md)的 A/B 规则。

## 1.18.2 范围

内容族：75% 的元素在建筑方块目录；179 个过程去掉木种约 77 个模板，主要是门、墙、椅的多格放置。按玩家变量、命令、给物品、效果、伤害、传送筛查命中 11 个元素，逐个读后只有传承之光离开元素自身，已归 fulu。家具箱 `Beechfurniture14` 为 27 格、无槽位过滤；牌位的写入过程 `SetPaiwei` 写 `plaquetxt`。

## 目标所有权与接口提案

内容表声明方块与家具，元素自身行为（开门、坐下、牌匾文字、家具容器）按实际内容保留，不统一成空方块。没有 `api`，其他系统只通过注册 ID 或标签引用。
