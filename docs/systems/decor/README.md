## 公开操作

实体椅子由Decor独占写入；经济发布`AuctionSeatRequestEvent`请求生成、乘坐、移除最近一把或移除范围全部椅子，Decor消费事件。其他系统只经注册ID/标签引用装饰资源，不能直接改实体持久化数据。
