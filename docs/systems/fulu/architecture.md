# 符箓知识、制作与释放：架构调查与提案

来源事实、已实现边界和未完成范围分别陈述；源码定位采用 [系统导航](../README.md)的 A/B 规则。

## 编号与实现类核对

符箓编号按 1.18.2 版本注册 ID 的数字部分书写，文档统一补足两位（如 `itemfulu_01` 简写为“01 号”）；`itemfulu_5001` 保留四位，不截断为 01。核对时以 `content.csv` 的 `legacy_id`、`element`、`source_file` 和 `target_id` 定位来源注册及元素，再以 `source-evidence.csv` 的 `element`、`source_file`、`line`、`target`、`implementation` 追踪到来源行为和目标实现。目标 Java 类名按职责命名，不能单凭英文类名推断编号；一类承载多个编号时，编号由其来源映射和分支参数共同确认。

## 1.18.2 结构

玩家 `huafufutou/huafutiandizhu/huafufudan` 保存知识列表；画符台方块实体另存当前符头、天地柱与符胆选择。制作表来自 `list.yvanchuxitong.fululist`。`B:HuizhifuluProcedure:80–128` 匹配符头/符胆，按天地柱选择四种墨条及等级，使用 `RuneLEVEL + 1` 判断，再给成品写 `fululevel`。经验为 `(fululevel * 2)^2 + 4`。

绘制菜单有纸/墨/成品；烧灰台是另一加工流程。51 个编号符箓物品还有对应弹体、实体、持续效果及回调。轮回符 `A:Fulutexiao37Procedure` 主动重置玩家多项数据，其生命周期不能并入普通攻击符。

## 目标所有权与实现边界

知识附件由 fulu 独占写入；画符台共享方块实体保存选择与库存，菜单不持有独立的玩家私有选择快照。成品组件保存符箓等级和实例信息。当前已实现知识学习、画符台选择/预览/绘制、烧灰架处理、传承之光及下文所列符箓施用、弹体和召唤物；世界自然获取及其他未接入的妖兽依赖等分支仍待完成。

已实现入口包括学习知识、选择组合、预览/绘制、烧灰和传承授予。施放交由能力执行时须保留符箓消费和特殊效果边界，轮回调用成长的专用操作，传送调用世界服务，伤害通过战斗入口。

## 对照要求

每张编号符箓都记录获取、制作/其它获取路径、使用条件、物品消耗、实体/声音/粒子和结束动作。不同等级成品合并条件以来源为准，不因 Item ID 相同就混合不同等级。数值和轮回保留字段按锁定来源实现，来源疑点集中登记。

### 首领符弹体与45/46来源边界（2026-11-14）

首领01火球术与飞雷符分别由`NpcTalismans.shootBossFireball`、`shootBossCannon`生成46号火球与45号火炮弹。入口保持原生箭伤害0.1、固定击退1、静音、眼部下方0.1格、速度1及无散布，只负责生成；技能时序属于Creature。首刻初始化在原生箭推进之后执行，已无重力的弹体不重新取品阶，既有箭主人、品阶、计数及实体持久状态负责保存。

45号`cannonTick`首刻取施放者实体`fulu45level`，非正值取`mana_Att`，随后清`fulu45level`；弹体团队取施放者玩家能力团队，非玩家首领按来源默认能力取空串，主人UUID写入弹体`belongToMasterUUID`。命中与14刻到期均以弹体位置分别扫描向各方向4格、2格AABB，按距离排序，不再重复把已换算半径除以2。命中经施放者敌友关系检查，外层固定火伤害`5×品阶`、内层`15×品阶`并击飞；内层目标经过两次来源遍历。到期按目标的本体实体团队与弹体首刻保存的实体团队比较，分别写`ManaAttackDamage=5×品阶/20×品阶`、保存的主人UUID、火属性、倍率1与独立攻击标记并击飞；内层覆盖外层标记。到期没有命令伤害，来源/current消费断链按[Combat正文](../combat/architecture.md)保留。

`typed_field_accesses.csv:1587–1589`分别对应45首刻玩家团队读取和46首刻玩家体质读取；目标经`Relations.team/entityTeam/setTeam`与`FuluUse.stateValue`的Xiulian公开读取承接，不访问其他系统持久化对象。41号弹体的独立`fulu41level`、主人和团队交接不参与本次修改。静态来源核对已执行，本增量转换、构建、结构测试与游戏运行未执行；先前46号实体出现检查不覆盖首刻快照、伤害、范围和保存重读，本次证据只在[月志](logs/2026-11.md#2026-11-14-首领符弹体与4546来源修正)记录。
