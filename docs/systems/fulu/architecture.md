# 符箓知识、制作与释放：架构调查与提案

来源事实、已实现边界和未完成范围分别陈述；源码定位采用 [系统导航](../README.md)的 A/B 规则。
## 1.18.2 结构

玩家 `huafufutou/huafutiandizhu/huafufudan` 保存知识列表；画符台方块实体另存当前符头、天地柱与符胆选择。制作表来自 `list.yvanchuxitong.fululist`。`B:HuizhifuluProcedure:80–128` 匹配符头/符胆，按天地柱选择四种墨条及等级，使用 `RuneLEVEL + 1` 判断，再给成品写 `fululevel`。经验为 `(fululevel * 2)^2 + 4`。

绘制菜单有纸/墨/成品；烧灰台是另一加工流程。51 个编号符箓物品还有对应弹体、实体、持续效果及回调。轮回符 `A:Fulutexiao37Procedure` 主动重置玩家多项数据，其生命周期不能并入普通攻击符。

## 目标所有权与实现边界

知识附件由 fulu 独占写入；画符台共享方块实体保存选择与库存，菜单不持有独立的玩家私有选择快照。成品组件保存符箓等级和实例信息。当前已实现知识学习、画符台选择/预览/绘制、烧灰架处理和传承之光的选择/授予入口；符箓施用、相关实体与效果、世界自然获取及其余特殊分支尚未完成。

已实现入口包括学习知识、选择组合、预览/绘制、烧灰和传承授予。施放交由能力执行时须保留符箓消费和特殊效果边界，轮回调用成长的专用操作，传送调用世界服务，伤害通过战斗入口。

## 对照要求

每张编号符箓都记录获取、制作/其它获取路径、使用条件、物品消耗、实体/声音/粒子和结束动作。不同等级成品合并条件以来源为准，不因 Item ID 相同就混合不同等级。数值和轮回保留字段需负责人批准后实施。
