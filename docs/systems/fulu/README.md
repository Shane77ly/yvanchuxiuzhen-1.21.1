## 公开操作

`CorpseTalismans.hasEmptySeal/seal`拥有50库存资格、扣符与5001载体写入；`CorpseReleaseEvent`只发布服务端顶面释放事实和载体副本。Creature独占选定字段和死亡实体恢复，Fulu不依赖Creature实现；来源玩家能力团队读取问题见[生物Q114](../creature/architecture.md#q114-尸体封存的选定字段与状态重置)。

`Fulu.createReward(Item, int, String)`承接Treasure成品符箓奖励，由Fulu写入实例品阶和品阶文字，复用既有Tooltip与自然施用链。Treasure只提供来源抽样值，不直接写符箓业务实例；本增量仅静态核对，运行边界见[月志](logs/2026-11.md#2026-11-14-宝箱成品符箓入口)。

`TalismanTamingEvent`在18号命中妖兽时同步通知Creature，提供服务端、目标、施放者和品阶；Fulu不依赖Creature实现。非妖兽的控制效果、缓慢及精力扣除由Fulu经Xiulian公开入口执行。`typed_field_accesses.csv:2098–2106`分别由Relations、Cultivation和ModifierKeys承接；具体边界见[神傀符正文](architecture.md#神傀符18控制与驯服2026-11-13)。

`NpcTalismans` 承接 creature 的修者 0101 符箓技能：`summonThunderPull` 生成 01 雷符实体并继承施放者友方集合，`activateFlameJet` 登记 02 喷火及生效计数，`activateWindPressure` 仅登记 03 风压标记与品阶，`shootQiSword` 写入 05 品阶并发射气剑。技能选择与 36 刻施放时序由 creature 持有；符箓实体、弹体及持续状态由 fulu 写入。03 未增加生效计数是来源实际行为，见[修者符箓调用](architecture.md#修者0101符箓调用2026-11-11)。本批仅完成静态来源核对，专项运行尚未执行。

`NpcTalismans.shootBossFireball / shootBossCannon`承接首领01的46号火球与45号飞雷符，按眼部下方0.1格、视线、速度1、无散布及静音生成来源弹体；入口不额外写品阶。Creature只持有技能时序，Fulu首刻读取品阶并写弹体自身快照；团队查询与写入经Relation，玩家体质读取经Xiulian公开接口，见[符弹体边界](architecture.md#首领符弹体与4546来源边界2026-11-14)。

`Fulu.knowledge(Player)` 查询玩家已掌握的符头、天地柱和符胆；知识按学习顺序保存为稳定编号，初始符头1、天地柱1–4、符胆1。`Fulu.unlockHead`、`Fulu.unlockCore` 是唯一学习写入口，统一处理去重、同步、反馈、符胆学习物品消费和符头烧灰标志；`Fulu.command` 承接原初系统命令的两个解锁分支。book 只执行书上已核 `fulumingling` 请求，不直接修改附件；传承之光经同一知识入口授予符头。

`FuluData` 独占玩家知识附件，保存并保留死亡/末地返回时的克隆，只同步本人；画符台当前符头、天地柱、符胆选择是方块实体共享状态，与知识列表分开。`typed_field_accesses.csv:5629–5640,5953–5954` 为本系统选择与学习读写；外部 `PlayerJoinGame:80,85`（表5705–5706）仅将旧中文“薇”修为“微”，目标稳定编号4对应“紫微帝君”，不再写已翻译知识字符串。书本动态字段不在该强类型表中，另据 `A:BookRightClick:46–52` 核对。

知识、绘制、烧灰首周期和传承授予已有内置目标版本客户端检查；传承世界自然布置、烧灰末槽结束及多层烟灰等剩余边界见月志。

15 号镇宅符只通过 relation 公开查询取得玩家团队和好友集合只读活视图，fulu 不直接修改 relation 持久化对象。同次运行放置后增删好友立即改变排斥判定；方块实体保存时写入当前集合，重载后持有独立集合。

施用：`FuluUse` 承担精力付款与持续效果登记，`FuluTick` 承担逐刻推进与结束；目前接入 01–36、38–49 号符（见[架构](architecture.md)“符箓施用共享框架”）。其余符（37）、轮回符、特殊符、全部食材自然获取、世界传承布置及其余来源内容仍按对应台账行推进。持续效果状态保存在 xiulian 的体质标签（键见 [tizhiitem_keys.csv](../xiulian/ledger/tizhiitem_keys.csv)），经 `Cultivation.editTizhi` 写入。41号受击状态由Fulu持有原生状态效果和实体自由NBT；施放者团队经Relation公开查询与实体写入口交接，落雷经Combat公开操作，不访问其他系统玩家持久化对象。
